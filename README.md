# FSU-2022-26
Projects from my time spent at FSU. These projects were very self-guided (Doesn't include programs/projects that may be reused by other students)

The first class I took with truly individual projects was Computational Evolutionary Biology. In this class, we used AI to help build code for the concepts we would learn. These concepts went from Newick trees, the coalescent, and many other high-level concepts. I included only my final project in the repo, as it shows that with the information I learned in the class, I found a topic that goes further. For the topic I decided to look into protein mutation matrices, there are a few variants I tested against eachother to see if with data I would get tress that differed a lot from eachother. The full paper and project are in the repo. 

A class I took that helped me understand biological data analysis broadly was Bioinformatics, taught in R at FSU. For a Midterm project, we used real RNA-Seq data from a list of datasets. I analyzed data on the effect of retinoic acid breakdown on proximal and distal limb regeneration in Axolotls. For the final project, I had analyzed SNPs in immune cells in a GWAS study. The final project had expectations of analysing larger data and having a more in-depth analysis. In both projects, you can find an .rmd file with the code, outputs, and the analysis I conducted. Tables are also provided. 

For my senior year, I also enrolled in Symbolic and Numeric Computation for Scientific Applications. In this course, we understood MATLAB semantics through weekly quizzes on the textbook. The class was experimenting with a different teaching style: we would read the textbook chapter and take quizzes, but use AI primarily through prompts. This course has shown me how to prompt ChatGPT to generate viable code and how to identify mistakes in ChatGPT's output. For the first project, I extended my work at the Kira Lab to also simulate how the rat responds to stimuli, using a coefficient to quantify how well the neurons generalize the stimulus. I also made a small program to take in neuronal data and see whether it had generalized the stimulus, using a threshold for how close the response had to be to be considered "generalized". For the second project, I developed educational game-theory simulations, including one that integrated genetics and evolution into the pigeon simulations. I had also investigated Q-learning in individual pigeons and a population of pigeons. As an extra side project, I made a playable prisoner's dilemma game.
